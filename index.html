    Como funciona o algoritmo?

    A solução utiliza recursão para dividir o problema em casos menores até chegar ao caso-base, quando resta apenas um disco. 

    function hanoi(
  n: number,
  origem: Pino,
  auxiliar: Pino,
  destino: Pino
): void {
  if (n === 1) {
    movimentos.push({ disco: 1, origem, destino });
    return;
  }

  hanoi(n - 1, origem, destino, auxiliar);
  movimentos.push({ disco: n, origem, destino });
  hanoi(n - 1, auxiliar, origem, destino);
}

    Caso-base: quando n === 1, o único disco é movido diretamente da origem para o destino.

    1ª chamada recursiva: move os n - 1 discos superiores da origem para o pino auxiliar.

    Movimento principal: move o disco n da origem para o destino.

    2ª chamada recursiva: move os n - 1 discos do pino auxiliar para o destino.
